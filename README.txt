THE BUZZER SHOW — FIXED VERSION

1. In your GitHub repository, open the existing index.html.
2. Choose the pencil/Edit button, select all the old code and replace it with the contents of this index.html.
   Alternatively, delete the old index.html and upload this one.
3. Commit the changes.
4. Keep GitHub Pages set to Deploy from a branch / main / /(root).

The RESET ROUND button stays visible below the buzzers and also appears on the result screen.
It unlocks the buzzers, clears the X/result overlay and stops the music.
